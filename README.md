# 🔮 Telegram-бот «Таро»

Вопрос → проверка формулировки и определение языка → расклад → **короткий бесплатный тизер** → слово-триггер → **глубокий платный разбор** (Telegram Stars).

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и OPENAI_API_KEY
python bot.py
```

Ключи читает только `config.py`; остальные модули берут их оттуда.

## Два уровня ответа

| | Бесплатный тизер | Платный разбор |
|---|---|---|
| Объём | 4–5 строк + строка-триггер (жёсткий лимит в коде) | 250–350 слов |
| Карты | одной строкой, позиции скрыты | полный расклад с позициями |
| Содержание | намёк на напряжение или скрытый фактор, без причин, совета и прогноза | **Ситуация → Чувства → Риск → Прогноз** (+ 2 шага) |
| Стоимость | 1 из `FREE_READINGS` (по умолчанию **2**) | 1 платный кредит |
| Модель | `OPENAI_MODEL_TEASER` (дешёвая) | `OPENAI_MODEL_READING` |

В разделе «Чувства» для вопроса об отношениях описываются чувства и мотивы другого человека, для остальных тем — скрытые мотивы и влияния.

```
вопрос ─► проверка + язык ─► баланс
            есть кредиты ─────────────► сразу ПОЛНЫЙ разбор (−1 кредит)
            иначе есть бесплатные ────► ТИЗЕР + «напиши: ГЛУБЖЕ»  (−1 бесплатный)
            иначе ────────────────────► paywall

«ГЛУБЖЕ» / кнопка ─► кредит есть? ─ да ─► полный разбор ТЕХ ЖЕ карт (тизер передаётся модели, противоречий нет)
                                   └ нет ► paywall; после оплаты одна кнопка открывает разбор
```

- Бесплатные расклады закончились → новые вопросы блокируются, показываются пакеты Stars. OpenAI при этом **не вызывается**.
- Тизер нельзя открыть дважды, и кредит не сгорает: при ошибке генерации он возвращается.
- Триггер срабатывает только на точное слово (`ГЛУБЖЕ`, `DAHA DERİN`, `DEEPER`, регистр и знаки препинания не важны), чтобы случайная фраза не списала кредит.

## Язык

- Язык определяется **тем же запросом**, что проверяет вопрос (поле `lang`), подсказкой служит язык интерфейса Telegram. Дополнительных вызовов нет.
- Системные промпты написаны на английском и содержат правило `LANGUAGE RULE: reply in the user's language, never mix languages`. Привязки к русскому нет, работает любой язык.
- Всё, что бот отправляет сам (меню, ошибки, оплата, строка-триггер, названия карт и позиций), локализовано для **ru / tr / en** в `i18n.py` и `tarot.py`. Для других языков текст толкования модель пишет на языке пользователя, а интерфейсные строки идут по-английски. Триггер для них — слово `DEEPER`, а строку-приглашение пишет модель, с английской страховкой.
- Чтобы добавить язык, скопируйте блок в `STRINGS`, `CTA`, `KEYWORDS`, `COMMANDS` (`i18n.py`) и названия в `tarot.py`.

## Файлы

| Файл | Что делает |
|---|---|
| `ai.py` | модерация, проверка + язык, промпты тизера и полного разбора |
| `bot.py` | сценарий free / paid, «ГЛУБЖЕ», оплата Stars |
| `i18n.py` | тексты интерфейса, слова-триггеры, определение языка UI |
| `tarot.py` | колода, 5 раскладов, локализованные названия карт |
| `db.py` | пользователи, лимиты, кредиты, раскрытие тизеров, платежи |
| `config.py` | ключи, модели, лимит, пакеты |

## Обновление существующей базы

Миграция автоматическая: при запуске `db.init()` добавляет недостающие колонки (`lang`, `tier`, `unlocked`, `deep_answer`). Старые записи считаются уже открытыми. Ничего удалять не нужно.

## Настройка

- **Лимит**: `FREE_READINGS` и `FREE_MODE` (`total` — на всё время, `daily` — в сутки).
- **Пакеты и цены**: `PACKS` в `config.py` (1 кредит = 1 полный разбор).
- **Стиль тизера**: `_teaser_system()` в `ai.py`; длина — `TEASER_MAX_LINES`.
- **Структура платного разбора**: `_deep_system()` в `ai.py`.
- **Тексты триггера**: `CTA` и `KEYWORDS` в `i18n.py`.

## Перед продакшеном

1. Для нескольких процессов замените SQLite и `busy`/`pending` в памяти на PostgreSQL и Redis; для нагрузки перейдите на webhook.
2. Возвраты Stars: `refundStarPayment` по `telegram_payment_charge_id` из таблицы `payments`.
3. Таблица `readings` хранит вопросы и ответы; отразите это в политике конфиденциальности.
4. Названия моделей в `.env` укажите актуальные для вашего аккаунта OpenAI.
